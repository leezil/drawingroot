# 001 두 점 사이의 거리

## 이번 단계의 목표

좌표 두 개를 받아 두 점 사이의 거리를 반환하는 `distance(a, b)` 하나를 구현합니다. 사용자가 그린 선은 순서가 있는 점들의 목록이므로, 점 사이 거리를 알면 다음 단계에서 선 전체 길이를 계산할 수 있습니다. 이후 그림 크기 조절과 모양 오차 측정에서도 사용합니다.

## 입력과 출력

`a = (0, 0)`, `b = (3, 4)`에서 각 점의 첫 번째 값은 x, 두 번째 값은 y입니다. x가 3, y가 4만큼 달라 두 점 사이 거리는 5입니다.

```python
from geometry import distance

result = distance((0, 0), (3, 4))
print(result)  # 5.0
```

이 단계에서는 각 점이 두 개의 유한한 숫자를 가진다고 가정합니다. 사용자 입력의 잘못된 형태를 확인하는 일은 추후 입력 검증 단계에서 다룹니다.

## 코드가 실행되는 순서

```python
import math

def distance(a, b):
    delta_x = b[0] - a[0]
    delta_y = b[1] - a[1]
    return math.hypot(delta_x, delta_y)
```

`import math`는 Python에 기본으로 포함된 수학 기능을 가져옵니다. 외부 패키지를 설치하지 않아도 됩니다.

`def`는 함수를 정의합니다. `a`, `b`는 호출할 때 전달받는 두 점입니다. 함수를 정의한 것만으로 계산이 실행되지는 않고 `distance(...)`로 호출해야 합니다.

`a[0]`은 a의 x, `a[1]`은 a의 y입니다. 좌표의 절대 위치보다 두 점 사이의 차이가 필요하므로 x와 y를 각각 뺍니다. 위 예제에서 `delta_x=3`, `delta_y=4`입니다.

`math.hypot(3, 4)`는 `sqrt(3² + 4²)`에 해당하는 피타고라스 거리를 구합니다. 표준 라이브러리의 구현을 사용하면 제곱·합·제곱근을 직접 작성하지 않아도 되고 큰 수나 작은 수에서도 수치적으로 안정적인 계산을 사용할 수 있습니다.

`return`은 계산 결과를 호출한 쪽으로 돌려줍니다. 이 함수 안에서 출력하지 않는 이유는 다음 함수가 반환값을 더하거나 비교하도록 하기 위해서입니다. 눈으로 볼 때만 호출한 쪽에서 `print`를 사용합니다.

## geometry.py에 따로 두는 이유

`geometry.py`는 좌표를 다루는 공통 함수의 위치입니다. 나중에 선 길이 함수와 경로 평가에서 `from geometry import distance`로 사용할 수 있습니다. 서버·지도 화면이 생겨도 이 함수는 같은 입력에 같은 출력을 내므로 독립적으로 확인할 수 있습니다.

## 단위를 구분하는 이유

이 함수는 평면 좌표를 계산하고 단위를 바꾸지 않습니다. 캔버스 픽셀 좌표면 결과도 픽셀이고, 미터로 변환된 좌표면 결과도 미터입니다. 지구 위 위도·경도를 그대로 넣어 미터 거리라고 해석하면 안 됩니다. 지도 좌표의 변환은 나중 단계에서 별도로 설명합니다.


첫 명령의 출력은 `5.0`입니다. 두 번째 명령은 대각선, 같은 점, 음수 좌표의 수직 거리, 방향·위치 변화에 대한 네 가지 테스트를 실행합니다. 테스트의 기대값은 미리 계산한 값이며 테스트가 같은 거리 공식을 다시 구현하지 않습니다.
