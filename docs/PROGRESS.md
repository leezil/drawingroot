GitHub 공개 저장소 `leezil/drawingroot`를 생성했습니다. 첫 기능은 두 점 사이의 평면 거리를 구하는 함수이며, 이 단계 다음에 구현합니다.

## 001 두 점 사이의 거리

2026-10-06 `geometry.py`에 `distance(a, b)`를 구현했습니다. x와 y 차이를 계산하고 `math.hypot`으로 평면 거리를 반환합니다. 입력 좌표의 단위를 유지하며 위경도의 미터 변환은 이후 단계입니다.

대각선 3·4·5, 같은 점, 음수 좌표의 수직 거리, 방향·위치 변화의 네 가지 테스트를 작성했으며 모두 통과했습니다. 직접 실행한 `distance((0, 0), (3, 4))`의 결과도 `5.0`으로 확인했습니다. 상세 설명과 실행 예제는 [001_DISTANCE.md](001_DISTANCE.md)에 있습니다.

다음 기능은 `length(points)`이며 아직 구현하지 않았습니다.
