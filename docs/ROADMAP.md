# 메인 프로젝트 학습 계획

각 단계는 설명하고 실행할 수 있는 작은 기능 하나입니다. 현재 테스트 프로젝트의 완성 파일을 통째로 가져오지 않고, 필요한 기능과 연결을 차례로 구성합니다. 아래 항목은 계획이며 완료 기록은 PROGRESS.md에서 확인합니다.

## 처음 배우는 함수

1. `distance(a, b)` — 두 점의 평면 거리. 입력 좌표 두 개가 숫자 하나로 바뀌는 과정.
2. `length(points)` — 점들을 순서대로 이은 선의 길이. distance를 반복해서 사용하는 과정.
3. `segment_distance(point, start, end)` — 점과 선분 사이의 거리. 경로가 원본 선에서 얼마나 벗어났는지 측정하는 기초.
4. 그림 좌표 검증 — 유효한 좌표열과 사용할 수 없는 입력을 구분.
5. 열린 선과 닫힌 선 판정 — 끝점이 출발점으로 돌아오는 조건.
6. 선을 일정한 간격으로 다시 샘플링 — 입력 지점 수가 달라도 비교할 수 있게 정리.

## 이후 기능을 나눌 기준

다음 큰 주제들도 실제 작업 전 함수·화면 동작·API 하나씩으로 더 나눕니다.

- 가장 작은 웹 페이지 → 캔버스 표시 → 클릭 좌표 → 선 그리기 → 지우기 → 좌표 전송.
- 가장 작은 HTTP 서버 → 상태 API → JSON 입력 → 검증 → 함수 호출 → 결과 표시.
- 노드 → 간선 → 인접 목록 → 가상 도로 → 최단길 → 접근 거리 → 실제 OSM 입력.
- 원본 선 배치 → 도로 지점 후보 → 구간 연결 → 거리 검사 → 모양 평가 → 후보 하나 반환.
- 카카오맵 연결 → 경로 표시 → 장소 검색 → 기준 위치 선택.
- 여러 출발점 → 여러 경로 → 후보 선택·정렬 → 꼭짓점 조정 → 불필요한 왕복 검사.
- 위치별 대표 탐색 → 선택 위치 상세 탐색 → 결과 재사용.
- 도로 저장·갱신 → 외부 조회 실패 처리 → 사전 다운로드 데이터 사용.
- 공개 API → 작업 대기열 → 영속 결과 → 웹 공개 → 모바일 연결.

프레임워크나 외부 서비스는 해당 단계에서 필요한 이유를 설명하고 선택합니다. 배우지 않은 기능을 미리 대량으로 추가하지 않습니다.
