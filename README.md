# drawingroot

사용자가 그린 선에 가까운 러닝 경로를 만드는 메인 프로젝트입니다. 작은 함수부터 직접 구현하고 확인하며 웹 화면, 도로 그래프, 경로 생성 API로 확장합니다.

공개 저장소: https://github.com/leezil/drawingroot

상위 `running`에 있는 기존 구현은 **테스트 프로젝트**이며 참고 자료입니다. 이 저장소는 그 코드에 의존하지 않는 독립 프로젝트로 구성합니다.

## 개발 방식

각 단계에서 입력과 출력, 필요한 이유, 구현 방법과 연결 관계를 설명합니다. 테스트로 동작을 확인한 뒤 기능별로 커밋합니다. 구현한 단계는 [진행 기록](docs/PROGRESS.md)에, 다음 순서는 [학습 계획](docs/ROADMAP.md)에 남깁니다.

처음에는 Python 표준 라이브러리만 사용합니다. Python 3.10 이상이면 별도 패키지 설치 없이 시작할 수 있습니다.

```powershell
python -m unittest discover -s tests -v
```

이 명령은 이 저장소의 루트 디렉토리에서 실행합니다. 웹 화면과 서버는 이후 단계에서 추가합니다.
