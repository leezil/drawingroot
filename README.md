# drawingroot

사용자가 그린 선에 가까운 러닝 경로를 만드는 메인 프로젝트입니다. 작은 함수부터 직접 구현하고 확인하며 웹 화면, 도로 그래프, 경로 생성 API로 확장합니다.

공개 저장소: https://github.com/leezil/drawingroot


## 개발 방식

각 단계에서 입력과 출력, 필요한 이유, 구현 방법과 연결 관계를 채팅으로 설명합니다. 기능 작업마다 로컬 테스트 환경을 실행하고 열어 사용자가 직접 확인할 수 있게 합니다. 커밋과 푸시는 사용자가 GitHub Desktop에서 직접 수행합니다. 진행 기록과 학습 계획은 사용자가 위키에 직접 정리하며, 별도 요청 없이는 설명 문서를 추가하지 않습니다.

처음에는 Python 표준 라이브러리만 사용합니다. Python 3.10 이상이면 별도 패키지 설치 없이 시작할 수 있습니다.

현재 첫 기능: [두 점 거리 함수 설명](docs/001_DISTANCE.md). `geometry.py`의 `distance(a, b)`를 구현했습니다.

```powershell
python -m unittest discover -s tests -v
```

이 명령은 이 저장소의 루트 디렉토리에서 실행합니다. 웹 화면과 서버는 이후 단계에서 추가합니다.
